# Frame

A simple movie catalog website developed as a college group project for a Front-End Development course.

About

Frame is a static website designed to showcase movies through a clean and organized interface.

The project was developed as part of a university assignment, focusing on the fundamentals of front-end development, semantic HTML, CSS styling, layout organization, and navigation between pages.

Pages
Home — Main page with featured movies and website navigation.
Movie Details — Page with additional information about selected movies.
Plans & Pricing — Pricing table presenting the available plans.

CSS3

Purpose

The main goal of this project was to apply fundamental front-end development concepts in a practical project, with a focus on semantic HTML, CSS layouts, visual organization, and usability.

Academic Project

Developed as a group project for the Front-End Development course at Universidade Positivo.
